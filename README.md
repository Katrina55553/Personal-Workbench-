# 我的工作台

一个用于待办、每日习惯、收支和自习记录的个人桌面工作台。React + TypeScript + Vite，数据只保存在当前浏览器。

## 开始使用

需要 Node.js **24** 和 npm。

```sh
npm ci
npm run dev
```

打开终端打印的 `http://127.0.0.1:5173/`。首次使用没有演示记录；记账分类和自习科目已预设，可在设置中新增、改名、停用。

右上角可切换亮色 / 暗色模式。首次打开使用系统外观，手动选择后保存在当前浏览器，刷新和页面切换后继续使用，并同步到同源标签页。外观偏好使用独立键 `personal-workbench-theme-v1`，不随业务备份导入导出。

## 检查与构建

```sh
npm run check
npx playwright install chromium
npm run test:e2e
npm run test:coverage
npm run preview
```

`check` 包括格式检查、ESLint、TypeScript、单元/组件测试和生产构建。`preview` 预览 `dist/`，默认地址 `http://127.0.0.1:4173/`。端到端测试自动启动生产预览服务。

其他命令：`npm run format` 自动格式化，`npm run test:watch` 持续运行单元测试。GitHub Actions 在推送或 PR 时执行检查和 Chromium 端到端测试；连接远端仓库后生效。

`dist/` 可放到静态 HTTP/HTTPS 服务，Hash 路由无需服务器路径回退。不要双击构建后的 HTML；模块资源需要通过 HTTP 服务加载。首期面向 1024 像素及以上桌面宽度，重点验证 1280 / 1440 / 1920。

## 数据与备份

- 新版使用 localStorage 键 `personal-workbench-v1`，不读取旧版键。
- 不同域名、协议或端口的数据各自独立；开发端口和预览端口也不共享数据。
- 设置 → 导出备份，下载包含四个模块及字典配置的 JSON。更换电脑、浏览器或清理数据前请先备份。
- 导入先校验版本、字段和引用并展示数量。确认后**整份替换**当前业务数据与配置，重置计时。建议先导出当前数据。
- 备份不包含计时状态。损坏的本机数据不会自动覆盖，设置中可导出原始数据供恢复。
- 保存失败时保留表单输入并显示错误。浏览器隐私模式、存储策略、空间限制可能影响保存。

金额按整数“分”存储，界面允许最多两位小数；自习时长为 1–1440 的整数分钟。日期使用浏览器本地日历，自习周统计从周一开始。习惯打卡从今天向前连续展示，默认显示近 14 天，可通过“查看更多日期”扩展历史并横向滚动补打；概览显示近七天。当前习惯连续天数在今天尚未打卡时延续昨天，缺一天则中断。

## 天气

概览右侧的天气卡片显示当前温度、天气、今日高低温与降水概率，以及从明天起连续三天的预报。点击“使用当前位置”授权浏览器定位；定位成功后显示“当前位置”。定位被拒绝、超时或不可用时，可点击“选择城市”搜索中文或英文名称，从带有地区与国家的候选中选择；选定后可随时“切换城市”。

天气与城市搜索来自 [Open-Meteo](https://open-meteo.com/)，个人非商业用途无需 API 密钥。天气来自预报模型，需联网获取。定位需要浏览器权限及 HTTPS 安全上下文，本机 `localhost` / `127.0.0.1` 开发与预览地址也可使用；普通 HTTP 部署可手动选择城市。

上次位置与天气缓存使用独立 localStorage 键 `personal-workbench-weather-v1`，不包含在业务备份中。进入概览先显示缓存，超过 30 分钟或所在地日期变化时自动更新；概览可见时每 30 分钟刷新，也可手动“刷新天气”。刷新失败会保留已有数据并显示更新时间，缺失字段显示“—”。日期与更新时间以天气所在地时区为准。页面不持续追踪位置，移动后可再次点击“使用当前位置”。

## 番茄钟

25 分钟专注 / 5 分钟休息，每个阶段结束后等待手动开始下一段。运行、暂停状态可跨页面和刷新恢复；根据截止时间计算剩余时长，后台节流不会延长会话。

专注完成时自动记录 25 分钟，归入**该阶段截止日期**。会话 ID 防止重复记录；专注完成与阶段切换原子保存。休息不计入学习，提前重置不记时，离开多天也只结算已开始的阶段。

现代 Chrome / Edge 通过 Web Locks 串行处理同源标签页的数据更新，并通过 storage 事件同步；其他浏览器降级为单标签页更新。提醒在工作台内显示。

## 代码结构

```text
src/
  app/          应用布局、路由、异常边界
  features/     概览、待办、习惯、记账、自习、设置
  data/         Zod 类型、预设数据、仓储、状态管理、计时结算
  shared/       基础组件、日期、弹窗、反馈、公共样式
  test/         组件测试初始化
tests/          Playwright 端到端测试
```

组件通过仓储更新数据，Zustand 订阅已保存快照；统计函数不依赖组件或 DOM。计时每秒只更新显示，到期或用户操作时才写入快照。新增业务应保持类型、计算、持久化与展示分离。

原始 `workbench-desktop.html` 和 `assets/` 保留为参考，未迁移旧数据。首期不包含账号、后端、同步服务或手机适配。
